# Tekete SafeSpace

## Getting Started

After cloning the repository:

1. Install PHP and Composer.
2. Run:

    composer install

3. Copy `.env.example` to `.env` and configure as needed.
4. Generate app key:

    php artisan key:generate

5. Run migrations:

    php artisan migrate

6. Start server:

    php artisan serve
